# 🏭 WARUNGku - Teaching Factory (TEFA) Repository
## Mobile Development (React Native) - SMK RPL Kelas 11 Fase F

Selamat datang di repository **WARUNGku**. Ini adalah repository bahan ajar berbasis **Teaching Factory (TEFA)** yang dirancang khusus untuk mata pelajaran Pemrograman Perangkat Bergerak di SMK jurusan Rekayasa Perangkat Lunak (RPL).

### 🚀 Filosofi Pembelajaran
Dalam kurikulum ini, siswa tidak hanya belajar "coding", tetapi **MEMBANGUN PRODUK**. Setiap baris kode yang ditulis adalah bagian dari aplikasi nyata yang memiliki nilai jual di industri.

1. **Produk Nyata**: Membangun aplikasi Kasir & Manajemen UMKM "WARUNGku".
2. **Standar Industri**: Menggunakan *clean code*, arsitektur yang *scalable*, dan dokumentasi profesional.
3. **Value Oriented**: Setiap fitur yang dibangun dijelaskan nilai bisnisnya (mengapa klien mau membayar untuk fitur ini).
4. **Sprint-Based**: Pembelajaran dibagi menjadi SPRINT mingguan layaknya tim developer profesional.

---

### 🛠 Tech Stack
- **Frontend**: React Native (Expo Managed Workflow)
- **Backend (Semester Genap)**: Laravel 11 + Sanctum
- **Database**: SQLite (Local) & MySQL (Cloud)
- **UI Library**: React Native Paper
- **State Management**: Context API & React Query

---

### 📂 Struktur Repository
- `semester-ganjil/`: Fokus pada produk "WARUNGku" versi offline-first (Local DB).
- `semester-genap/`: Fokus pada "WARUNGku PRO" (Cloud Sync, API, Multi-user).
- `SILABUS.md`: Roadmap lengkap 36 pertemuan.
- `AI_GENERATION_GUIDE.md`: Panduan instruksi untuk AI dalam menghasilkan materi.
