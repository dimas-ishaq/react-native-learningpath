# 📅 Silabus & Roadmap Produk: WARUNGku (36 Pertemuan)

## 🏛 Semester Ganjil: "WARUNGku" (Local POS)
**Goal**: Menghasilkan aplikasi kasir mandiri yang bisa digunakan offline oleh warung lokal.

| Pertemuan | Nama Sprint / Topik | Output Produk (Increment) |
|-----------|----------------------|---------------------------|
| P01 | Project Kickoff & Branding | App terinstall, Splash Screen, App Icon |
| P02 | Design System & UI Components | Library Button, Card, Typography siap pakai |
| P03 | Navigation & Architecture | Struktur Tab & Stack Navigator lengkap |
| P04 | Auth UI & Validasi | Layar Login/Register & AsyncStorage |
| P05 | Manajemen Produk (C & R) | Form Tambah Produk & List Produk (SQLite) |
| P06 | Manajemen Produk (U & D) | Fitur Edit, Hapus & Low Stock Warning |
| P07 | Layar Kasir POS - Cart | Sistem Keranjang Belanja & Kalkulasi |
| P08 | Checkout & Receipt | Transaksi Selesai & Generate Struk Digital |
| P09 | Riwayat Transaksi | List Penjualan & Filter Tanggal |
| P10 | Dashboard & Statistik | Grafik Penjualan (Daily/Weekly) |
| P11 | Export & Backup Data | Export CSV & Database Backup |
| P12 | Store Profile & Settings | Konfigurasi Nama Toko & Pajak |
| P13 | Performance Optimization | Smooth UI, Image Caching, Memoization |
| P14 | Push Notification (Local) | Pengingat Stok Menipis & Laporan |
| P15 | UAT & Bug Fixing | Aplikasi Stabil & Bebas Bug |
| P16 | Build APK & Pitching | File APK Siap Install & Pitch Deck |
| P17 | Review & Mock Exam | Penguatan Materi |
| P18 | **Ujian Praktik Ganjil** | Implementasi Fitur Baru (Hutang/Resep) |
