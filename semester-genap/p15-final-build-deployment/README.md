# Pertemuan 15 - Capstone: Build, Test & Deploy

## 🏭 Konteks Industri
Tahap akhir dari siklus pengembangan software adalah **Release**. Di industri, ini bukan sekadar membuat APK, tapi memastikan aplikasi siap menghadapi ribuan pengguna nyata. Kita beralih dari format APK (untuk demo) ke format **AAB (Android App Bundle)** yang diwajibkan oleh Google Play Store karena lebih efisien dan ringan bagi pengguna.

Seorang Lead Developer harus memastikan aplikasi memiliki dokumentasi yang lengkap (*Technical & User Docs*) serta strategi pengujian di lingkungan yang mirip produksi (Internal Testing). Mempublikasikan aplikasi ke toko resmi meningkatkan kredibilitas Anda sebagai pengembang profesional berkali-kali lipat.

## 🎯 Sprint Goal
Menghasilkan bundle aplikasi final yang siap rilis ke Play Store dan menyusun landing page promosi produk.

## 📦 Product Increment
- [x] File AAB (Android App Bundle) Release WARUNGku PRO.
- [x] Dokumentasi teknis (README.md) yang mencakup cara instalasi API & App.
- [x] Setup Landing Page produk sederhana (Situs web promosi).
- [x] Laporan hasil Internal Testing (Google Play Console concept).

## 💰 Nilai Bisnis
Aplikasi yang sudah terbit di Play Store memiliki nilai kepercayaan yang sangat tinggi bagi UMKM. Ini membuktikan bahwa produk Anda sudah melewati verifikasi keamanan dan standar kualitas Google. Memiliki landing page juga memudahkan proses pemasaran digital, memungkinkan Anda mendapatkan klien baru melalui pencarian internet.

## ⏱ Alokasi Waktu (240 menit)
- **15 menit**: Standup - Review Onboarding & Help Center.
- **30 menit**: Teori: App Bundle (AAB) vs APK & Google Play Console Pipeline.
- **150 menit**: Coding Sesi: Build AAB & Membuat Landing Page HTML/React.
- **30 menit**: Peer Review: Cek kelengkapan dokumentasi README.
- **15 menit**: Sprint Review.

## 📋 Definition of Done
- [ ] Berhasil meng-generate file `.aab` menggunakan EAS Build.
- [ ] File README mencakup fitur, prasyarat, dan langkah setup backend/frontend.
- [ ] Landing page menampilkan screenshot aplikasi dan link download/kontak.
- [ ] Seluruh file `.env` telah dipisahkan dari repositori utama.
