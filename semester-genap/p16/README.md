# Pertemuan 16 - Go-To-Market Strategy (Pitching & Pricing)

## 🏭 Konteks Industri
Di industri teknologi, ada pepatah: "Produk terbaik tidak selalu menang, tapi produk yang dipasarkan paling baiklah yang menang." Banyak developer membangun aplikasi hebat tetapi gagal karena tidak tahu cara menjualnya. Tahap **Go-To-Market (GTM)** adalah strategi bagaimana produk Anda sampai ke tangan pelanggan dan mulai menghasilkan uang.

Anda harus memahami siapa kompetitor Anda (seperti Moka POS atau Kasir Pintar) dan apa keunggulan unik Anda (*Unique Selling Point*). Menentukan harga juga bukan sekadar menebak; Anda harus menghitung biaya server, waktu pengembangan, dan daya beli target pasar UMKM.

## 🎯 Sprint Goal
Menyusun strategi komersial lengkap dan materi presentasi bisnis untuk menjual aplikasi WARUNGku PRO.

## 📦 Product Increment
- [x] Analisis Kompetitor (Feature Comparison Matrix).
- [x] Paket Harga SaaS (Starter, Bisnis, Enterprise).
- [x] Pitch Deck Bisnis (10-12 Slide).
- [x] Demo Script & FAQ Penjualan (Menjawab keberatan klien).

## 💰 Nilai Bisnis
Kemampuan menjual (*Sales & Pitching*) adalah "Superpower" bagi seorang developer. Siswa yang bisa mendemokan nilai ekonomis aplikasi (misal: "Dengan aplikasi ini, Bapak hemat biaya admin Rp 500rb/bulan") akan jauh lebih sukses dibanding yang hanya menjelaskan fitur teknis. Ini adalah langkah awal membangun startup software sendiri.

## ⏱ Alokasi Waktu (240 menit)
- **15 menit**: Standup - Review Build Produksi & Landing Page.

- **45 menit**: Roleplay: Siswa berperan sebagai Developer vs Pemilik Warung.
- **15 menit**: Sprint Review.

## 📋 Definition of Done
- [ ] Dokumen Analisis Kompetitor mencakup minimal 2 aplikasi serupa di Play Store.
- [ ] Struktur paket harga memiliki perbedaan manfaat yang jelas antara satu dengan lainnya.
- [ ] Pitch Deck profesional dengan visual yang menarik (Gunakan Canva/Slides).
- [ ] Siswa mampu menjawab 3 pertanyaan tersulit klien (misal: "Kenapa harganya mahal?", "Bagaimana kalau internet mati?").
