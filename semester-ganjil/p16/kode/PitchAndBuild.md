# 🚀 Struktur Pitch Deck & Demo Script - WARUNGku

## 📊 Struktur Slide Pitch Deck (Rekomendasi)
1. **Cover**: Nama Produk & Logo (WARUNGku: Solusi Digital Warung Masa Kini).
2. **Masalah (Pain Points)**: Sulit catat stok, antrean kasir lama, struk sering hilang.
3. **Solusi**: Memperkenalkan WARUNGku sebagai asisten kasir pintar.
4. **Fitur Unggulan 1**: Manajemen Stok Otomatis & Notifikasi.
5. **Fitur Unggulan 2**: Kasir POS Cepat dengan Struk Digital.
6. **Fitur Unggulan 3**: Laporan Omzet & Grafik Visual Real-time.
7. **Kelebihan**: Offline-first (tetap jalan tanpa internet), Ringan untuk HP jadul.
8. **Testimoni/Simulasi**: Keuntungan yang didapat (Hemat waktu & Biaya).
9. **Harga & Paket**: Pilihan harga jual atau berlangganan.
10. **Closing**: Kontak & Ajakan untuk mencoba demo.

## 🛠 Instruksi Build (Command Line)
Siswa diminta menjalankan perintah berikut di terminal:
```bash
# 1. Install EAS CLI (jika belum)
npm install -g eas-cli

# 2. Login ke akun Expo
eas login

# 3. Konfigurasi Project
eas build:configure

# 4. Build APK (Tipe Preview)
eas build --platform android --profile preview
```
*Catatan: Pastikan `app.json` sudah memiliki `android.package` yang unik.*
