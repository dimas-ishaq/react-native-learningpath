# Pertemuan 10 - Dashboard Laporan & Statistik Visual

## 🏭 Konteks Industri
Seorang pemilik bisnis tidak punya waktu untuk membaca ribuan baris transaksi setiap hari. Mereka butuh **Dashboard**. Dashboard adalah "Cockpit" bagi pemilik warung untuk melihat kesehatan bisnis mereka dalam hitungan detik. 

Di industri, kemampuan menyajikan data secara visual (grafik/chart) sangat bernilai. Grafik membantu pemilik toko melihat tren: "Hari apa yang paling ramai?", "Jam berapa stok biasanya habis?", dsb. Developer yang bisa membangun dashboard informatif memberikan nilai tambah yang besar bagi produk SaaS (Software as a Service).

## 🎯 Sprint Goal
Membangun dashboard bisnis yang merangkum performa penjualan secara visual dan informatif.

## 📦 Product Increment
- [x] Kartu Statistik (Omzet Hari Ini, Total Transaksi, Produk Terlaris).
- [x] Widget "Stok Menipis" untuk peringatan cepat.
- [x] Grafik Penjualan Sederhana (Stylized UI atau Chart Kit).
- [x] Ringkasan Top 3 Produk paling menguntungkan.

## 💰 Nilai Bisnis
Dashboard adalah fitur "Wow" yang sering menjadi penentu apakah klien akan membeli aplikasi atau tidak. Ini adalah bagian yang paling sering ditunjukkan saat demo produk. Dashboard yang baik membantu UMKM mengambil keputusan berbasis data, bukan sekadar perasaan (insting).

## ⏱ Alokasi Waktu (240 menit)
- **15 menit**: Standup - Review Riwayat Transaksi.
- **30 menit**: Teori: Business Intelligence untuk UMKM & Visualisasi Data.
- **150 menit**: Coding Sesi: Membuat Layout Dashboard & Statistik.
- **30 menit**: Peer Review: Cek keakuratan ringkasan data.
- **15 menit**: Sprint Review.

## 📋 Definition of Done
- [ ] Angka omzet muncul dengan format Rupiah yang benar.
- [ ] Terdapat perbedaan warna visual (misal: Hijau untuk naik, Merah untuk turun/stok habis).
- [ ] Dashboard merespon data terbaru secara otomatis.
- [ ] Layout tetap proporsional di layar HP kecil maupun besar.
