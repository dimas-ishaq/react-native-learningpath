# Pertemuan 16 - Build APK & Persiapan Demo Klien

## 🏭 Konteks Industri
Kode yang bagus tidak ada gunanya jika hanya tertahan di laptop developer. Di industri, tahap akhir adalah **Deployment** dan **Sales Pitch**. Anda harus bisa mengubah kode tersebut menjadi file yang bisa diinstall di HP klien (APK) dan meyakinkan mereka bahwa aplikasi Anda adalah solusi terbaik untuk masalah mereka.

Seorang developer profesional juga harus memiliki jiwa **Entrepreneur**. Anda tidak hanya menjual "fitur", tapi menjual "solusi". Kemampuan mendemokan aplikasi dengan lancar dan menjelaskan nilai ekonomisnya (ROI - Return on Investment) adalah apa yang membedakan developer biasa dengan *Solution Architect* yang dibayar mahal.

## 🎯 Sprint Goal
Menghasilkan file instalasi (APK) final dan materi presentasi produk yang meyakinkan.

## 📦 Product Increment
- [x] File APK Release "WARUNGku" (Siap install).
- [x] Dokumen Pitch Deck (10 Slide Utama).
- [x] Demo Script (Alur demo 10 menit).
- [x] Strategi Penetapan Harga (Pricing Strategy).

## 💰 Nilai Bisnis
Tahap ini adalah tahap "Closing". Memiliki APK yang siap pakai memungkinkan klien untuk langsung mencoba (*Free Trial*), yang meningkatkan peluang penjualan hingga **80%**. Pitch deck yang profesional menunjukkan bahwa Anda serius dan kompeten, sehingga Anda bisa menegosiasikan harga proyek yang lebih tinggi.

## ⏱ Alokasi Waktu (240 menit)
- **15 menit**: Standup - Review Hasil Testing & Fix.
- **30 menit**: Teori: Deployment Pipeline (EAS) & Seni Presentasi Produk.
- **150 menit**: Sesi Kerja: Build APK & Menyusun Pitch Deck.
- **30 menit**: Mock Pitch: Latihan presentasi di depan kelas.
- **15 menit**: Sprint Review.

## 📋 Definition of Done
- [ ] File APK berhasil digenerate dan bisa diinstall di HP fisik.
- [ ] Nama aplikasi, Icon, dan Splash Screen muncul dengan benar setelah install.
- [ ] Slide Pitch Deck mencakup: Masalah, Solusi, Fitur Utama, dan Harga.
- [ ] Demo script mencakup alur dari Login hingga Cetak Struk.
