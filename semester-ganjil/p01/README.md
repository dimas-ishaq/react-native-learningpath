# Pertemuan 01 - Project Kickoff & Branding

## 🏭 Konteks Industri
Di dunia industri, "Kesan Pertama" adalah segalanya. Saat seorang developer mempresentasikan produk ke klien (pemilik UMKM), hal pertama yang mereka lihat bukan kodenya, melainkan **Branding**. Aplikasi yang memiliki *Splash Screen* beranimasi dan logo yang profesional akan langsung meningkatkan kepercayaan klien bahwa aplikasi ini layak dibayar mahal.

Setup proyek yang benar di awal (folder structure, theme configuration) adalah kunci agar aplikasi tidak berantakan saat fitur bertambah banyak di masa depan.

## 🎯 Sprint Goal
Membangun pondasi aplikasi **WARUNGku** yang siap dipresentasikan ke klien secara visual.

## 📦 Product Increment
- [x] Project Expo "WARUNGku" terinisialisasi.
- [x] Struktur folder standar industri (src-based).
- [x] Splash Screen dengan logo brand WARUNGku.
- [x] Konfigurasi tema warna dasar (Primary: Blue/Green UMKM style).

## 💰 Nilai Bisnis
Fitur branding (Splash screen & Logo kustom) biasanya bernilai **Rp 500.000 - Rp 1.000.000** dalam sebuah kontrak proyek sebagai bagian dari identitas digital bisnis klien.

## ⏱ Alokasi Waktu (240 menit)
- **15 menit**: Standup & Planning.
- **30 menit**: Teori: Mengapa struktur folder & branding itu penting?
- **150 menit**: Coding Sesi: Setup Expo & Splash Screen.
- **30 menit**: Peer Code Review.
- **15 menit**: Sprint Review & Demo.

## 📋 Definition of Done
- [ ] Aplikasi bisa dijalankan di HP (via Expo Go).
- [ ] Splash screen muncul minimal 2 detik saat app dibuka.
- [ ] Logo WARUNGku muncul di tengah layar dengan background warna brand.
- [ ] Pesan commit Git: `feat: initial project setup and branding`.
